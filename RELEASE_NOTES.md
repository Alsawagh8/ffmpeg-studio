## v0.4.0 — Release Notes / ملاحظات الإصدار

### 🇬🇧 What's New & Improvements (English)
- **Video Preview & MediaInfo Card:** Added a live `2×2` preview grid showing 4 real frames extracted from the selected video alongside a clean, MediaInfo-style summary card on the home tab.
- **HandBrake-Style Subtitles Tab:** Added an interactive subtitle track selector (`All Tracks` / `None` / individual track toggles) plus external `.ass` / `.srt` support (Hardsub & Softsub) that automatically preserves original `.ass` styling.
- **Color Depth & Smart Auto-Encode:** Added color depth selection (`8-bit` / `10-bit` / `12-bit` / `Auto`), automatic fallback from `copy` to `libx264` when filters or burn-in subtitles are active, and a cleaner output format list.
- **Quick Folder Access:** Added an **Open Folder** button to immediately open the output directory on both Linux and Windows.

---

### 🇸🇦 ما الجديد والتحسينات (العربية)
- **معاينة الفيديو وبيانات MediaInfo:** إضافة شبكة عرض 4 لقطات حقيقية من الفيديو في الصفحة الرئيسية بجانب بطاقة معلومات منسقة وواضحة.
- **تبويب الترجمة المتكامل (Subtitles):** اختيار تراكات الترجمة الداخلية بأسلوب HandBrake، ودعم حرق ودمج الترجمات الخارجية مع الحفاظ التلقائي على تنسيق ملفات ASS الأصلي.
- **عمق الألوان والتحويل الذكي:** إضافة خيارات 8-bit و 10-bit و 12-bit، والتحويل التلقائي الذكي عند استخدام الفلاتر أو حرق الترجمة، وتنظيف قائمة الصيغ.
- **فتح المجلد:** إضافة زر لفتح مجلد الحفظ مباشرةً بعد أو قبل التحويل.
